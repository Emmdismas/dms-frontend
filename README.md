# DMS Frontend (React + Vite + TypeScript)

Web Frontend ya **Dealer Management System (DMS)** iliyojengwa kwa **React 19, Vite 7, TypeScript, na Tailwind CSS v4**.

Programu hii inawasiliana na seva ya **DMS Backend (`dms-backed`)** kupitia REST API (`/api/v1`).

## Jinsi ya Kuendesha (Development)

```bash
npm install
npm run dev
```

Kwa chaguo-msingi inawaka kwenye `http://localhost:3001` na inaelekeza maombi ya `/api` kwenda `http://127.0.0.1:8001`.

## Kujenga kwa Uzalishaji (Production Build)

```bash
npm run build
```

Mafaili yote yaliyojengwa yatatengenezwa ndani ya folda la `dist/`.
